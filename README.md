# Tinkercad 功能動畫教室

生活科技 3D 建模入門教學網頁。

## 功能

1. **功能示範動畫**：點選左側 16 個功能圖示（放置形狀、移動、抬升、放到平面、旋轉、調整尺寸、顏色、鏡射、實心/挖空、群組、取消群組、對齊、複製並重複、工作平面、尺規、視角控制），中間的仿 Tinkercad 視窗會自動播放示範動畫，搭配步驟說明、快捷鍵提示。學生只需觀看，不需操作。
2. **拍照 → AI 建模建議**：上傳同一物品的 1~3 張照片，透過 OpenAI API（需自備 API 金鑰）分析，產生：
   - 建議使用的操作功能與理由（點選可跳到該功能的示範）
   - 零件清單（形狀、尺寸、位置、旋轉）
   - 建模步驟，並自動播放完整的建模模擬動畫（含真實的挖空/群組布林運算）
   - **AI 自我檢查**（預設開啟）：第一版規劃完成後，網頁會把模型畫成四視角預覽圖（正面/右側/斜角/俯視），連同原照片再交給 AI 比對、修正方向與比例
   - 結果會保存在瀏覽器「最近的分析結果」，可下載建模資料 JSON、再載入
   - 下載 STL（可在 Tinkercad 以「匯入」載入）
   - 沒有金鑰也可點「筆筒、馬克杯、小房子」範例觀看
3. **下載影片**：兩種動畫播放器都有「下載影片」按鈕，會從頭重播並錄成影片（電腦版 Chrome / Edge 選擇「這個分頁」可完整錄下介面；其他瀏覽器使用相容模式，錄 3D 畫面與字幕）

## 使用方式

- 線上版：GitHub Pages（見 repo 首頁右側 About 連結）
- 本機：任何靜態網頁伺服器皆可，例如在資料夾中執行 `python -m http.server`，再開啟 `http://localhost:8000`
  （因使用 ES 模組，直接雙擊 `index.html` 可能無法執行）
- 網址加上 `#group`、`#rotate` 等可直接開啟指定功能；`#ai` 直接開啟 AI 頁。

## 關於 API 金鑰

金鑰只會由瀏覽器直接送到 `api.openai.com`，不經過其他伺服器；勾選「記住」才會存在該瀏覽器的 localStorage。課堂公用電腦請勿勾選。預設模型 `gpt-5-mini`（立體方向判斷較準）；`gpt-4o-mini` 較快較便宜但準確度較低。

## 檔案結構

```
index.html        頁面
style.css         樣式
js/scene.js       3D 舞台、形狀、CSG 群組、時間軸
js/director.js    游標、點擊、拖曳、框選、量角器等示範動作
js/demos.js       16 項功能的示範腳本
js/plan.js        AI/範例建模計畫 → 模擬動畫；離線範例
js/ai.js          OpenAI API 呼叫、提示詞、自我檢查
js/recorder.js    動畫錄影下載
js/icons.js       圖示
vendor/           three.js、three-mesh-bvh、three-bvh-csg（MIT）
```

本頁為教學模擬，介面為示意，非 Autodesk 官方產品。
